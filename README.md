# java-lotto-precourse


## 기능 구현 목록
| 계층 | 클래스 | 역할 |
|------|----------|------|
| **Controller** | `LottoController` | 프로그램 실행 흐름 제어 |
| **Service** | `LottoService` | 로또 생성, 당첨 결과 및 수익률 계산 |
| **View** | `InputView`, `OutputView` | 사용자 입력 및 결과 출력 |
| **Model** | `Lotto` | 로또 번호 저장, 검증, 비교 기능 |

---

### 1. 로또 구입 금액 입력
- [ ] 1,000원 단위로 입력받음  
- [ ] 1,000원으로 나누어떨어지지 않으면 예외 발생  

### 2. 로또 발행 및 출력
- [ ] 구입 금액 / 1000 만큼 자동 발행  
- [ ] 각 로또는 1~45 사이의 중복 없는 6개 숫자  
- [ ] 번호는 오름차순 정렬  

### 3. 당첨 번호 및 보너스 번호 입력
- [ ] 쉼표(,)로 구분된 당첨 번호 6개 입력  
- [ ] 보너스 번호 1개 입력  

### 4. 결과 계산 및 수익률 출력
- [ ] 각 로또와 당첨 번호 비교 후 등수 계산  
- [ ] 등수별 개수 및 총 수익률을 출력
